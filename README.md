# Future Mod (Forge 1.20.1)
Añade: Mena de acero (piedra y pizarra abismal), Acero sin cocer y Lingote de acero.
- La mena suelta Acero sin cocer (Fortuna aplica; Toque de seda suelta la mena).
- El lingote SOLO se obtiene en el Alto Horno.
- Genera en el Overworld, capas -64 a 40.

## Compilar
1. Descarga el Forge MDK 1.20.1-47.3.0 (files.minecraftforge.net) y copia de él `gradle/`, `gradlew` y `gradlew.bat` a este proyecto.
2. Necesitas JDK 17.
3. `./gradlew build` -> el .jar queda en `build/libs/`. Cópialo a la carpeta `mods`.
